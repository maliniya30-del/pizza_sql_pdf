# pizza_sql_pdf
1.📊 Pizza Sales Analysis using SQL
This project contains a collection of SQL queries designed to analyze a pizza sales dataset and extract meaningful business insights. The queries focus on key performance indicators (KPIs), sales trends, and product performance to support data-driven decision-making.

2.🔍 Key Objectives
Analyze overall sales performance
Track customer ordering behavior
Identify best and worst performing products
Understand sales distribution across categories, sizes, and time periods

3.📈 Key Performance Indicators (KPIs)
The following metrics are calculated using SQL:

Total Revenue – Overall income generated from pizza sales
Average Order Value – Revenue per order
Total Pizzas Sold – Total quantity of pizzas sold
Total Orders – Number of unique customer orders
Average Pizzas per Order – Customer purchase behavior

4.📅 Sales Trend Analysis
Daily Order Trends – Analyze order patterns by day of the week
Monthly Order Trends – Identify high and low-performing months

5.📊 Sales Distribution Insights
Percentage of Sales by Category (Monthly) – Contribution of each pizza category
Quarterly Sales by Pizza Size – Revenue distribution based on pizza sizes
Total Sales by Category – Revenue generated by each category

6.🏆 Product Performance Analysis
Top 5 Best Sellers (Revenue) – Highest revenue-generating pizzas
Top 5 Best Sellers (Quantity) – Most frequently sold pizzas
Bottom 5 Sellers (Orders) – Least popular pizzas

7.🛠️ Tools & Technologies
SQL Server Management Studio (Structured Query Language)
Dataset table: pzsld

8.💡 Insights Gained
This project helps in:

Identifying customer preferences
Improving inventory and menu planning
Enhancing sales strategies
Supporting business decision-making with data
